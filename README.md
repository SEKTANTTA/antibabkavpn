# АнтиБабкаВПН

Подписка для обхода обычных блокировок, белых списков мобильного интернета и доступа к ИИ (ChatGPT, Claude, Gemini и др.).
Серверы собираются из публичных списков [zieng2/wl](https://github.com/zieng2/wl) и [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia): дубли убраны, названия понятные, серверы разложены по назначению. Зарубежные серверы идут сверху, российские в самом низу.

## Какой файл взять

| Что нужно | Файл | Как использовать |
|---|---|---|
| **ОДНА ссылка: авто-сервер + все серверы** | `auto.json` | Подписка в формате Xray JSON (Happ, v2rayN, v2rayNG) |
| Всё сразу | `all.txt` | Ссылка на подписку, любой клиент |
| Белые списки | `whitelist.txt` | Ссылка на подписку |
| ИИ (ChatGPT, Claude, Gemini, Grok...) | `ai.txt` | Только зарубежные серверы |
| Обычные блокировки (YouTube, Instagram...) | `regular.txt` | Только зарубежные серверы |
| Только российские серверы | `ru_only.txt` | Ссылка на подписку |
| Готовый конфиг с авто, белые списки | `clash_whitelist.yaml` | Clash Meta / Mihomo |
| Готовый конфиг с авто, обычный режим | `clash_regular.yaml` | Clash Meta / Mihomo |

## Что в `auto.json` (по порядку)

1. `🌍 АВТО Обычные блокировки`: самый быстрый из зарубежных серверов
2. `🤖 АВТО (зарубежные, ИИ отдельно)`: только зарубежные, домены ИИ идут через серверы, где ИИ доступен
3. `📶 АВТО Белые списки`: серверы, подходящие для белых списков (зарубежные сверху)
4. `🧠 АВТО ИИ`: только серверы, где работают ChatGPT, Claude, Gemini
5. дальше каждый сервер отдельно, российские внизу

Пинг проверяется раз в минуту, при поломке сервера клиент переключается сам.

## Как читать название сервера

`🇩🇪 Германия #3 · 🤖 ИИ · 🌍 Блокировки · 📶 Белые списки`

- флаг, страна, номер сервера в стране
- для чего подходит: `🤖 ИИ`, `🌍 Блокировки` (YouTube, Instagram и т.д.), `📶 Белые списки`
- метки `📶` нет у серверов из списка «только обычные блокировки»: при белых списках они могут не работать
- у российских серверов только `📶 Белые списки`: через них ИИ и заблокированные сайты не откроются

## Как добавить в приложение

1. Скопируй ссылку на нужный файл (см. ниже про хостинг).
2. В приложении: «Добавить подписку» → вставь **ссылку**, а не содержимое.
3. Включи автообновление раз в час.
4. Выбери первый пункт `🌍 АВТО` или `🤖 АВТО` и подключайся.

## Свой хостинг с автообновлением

1. Создай публичный репозиторий на GitHub и залей туда все эти файлы (включая папку `.github`).
2. Вкладка Actions → включи workflow «Обновление АнтиБабкаВПН». Раз в час он скачает свежие серверы и пересоберёт подписку.
3. Ссылка: `https://raw.githubusercontent.com/<твой_ник>/<репозиторий>/main/auto.json`
   (или `all.txt`, `ai.txt`, `clash_whitelist.yaml` и т.д.)

## Проверка серверов на работоспособность

В репозитории есть `probe.py`: он поднимает Xray, проходит через каждый сервер и обращается на Cloudflare. Если ответ пришёл, сервер живой, а заодно определяется реальная страна выхода и задержка.

- **Автоматически:** workflow из `.github/workflows/update.yml` запускает проверку каждый час. Нерабочие зарубежные серверы из списка «только блокировки» убираются, внутри страны серверы идут от быстрых к медленным.
- **Вручную на своём компьютере:** скачай Xray-core, затем `python3 probe.py ПУТЬ_К_xray build.py probe.json all.txt` и `python3 build.py all.txt out --alive probe.json`.
- **Ограничение:** проверка идёт из-за границы (GitHub-раннер). Она не показывает, пропускает ли сервер белые списки мобильного интернета в России. Поэтому серверы из белых списков и российские не удаляются, их проверяет авто-выбор в твоём клиенте.

## Важно

- Это чужие публичные серверы. Их владельцы технически могут видеть, на какие домены ты ходишь. Не вводи через них пароли от банков и госуслуг без необходимости.
- Серверы живут от нескольких минут до суток, поэтому нужны автообновление и авто-выбор.
- В Clash-конфиги не попадают серверы со сложными XHTTP-настройками. В `auto.json` и `.txt` они есть.
